# Lov na krugove

## O projektu

Lov na krugove je browser igra razvijena kao samostalni fakultetski projekat koristeći HTML, CSS i JavaScript. 
Cilj igre je upravljati krugom, sakupljati manje krugove kako bi igrač rastao te izbjegavati veće krugove koji predstavljaju opasnost.
Projekat je razvijen s ciljem primjene znanja iz razvoja web aplikacija, rada sa HTML5 Canvas elementom, animacija, detekcije sudara i implementacije game loop mehanizma.

## Funkcionalnosti
Aplikacija omogućava:
* upravljanje igračevim krugom pomoću strelica na tastaturi,
* nasumično kretanje krugova unutar scene,
* detekciju sudara između igrača i ostalih krugova,
* rast igrača nakon sakupljanja manjih krugova,
* završetak igre pri sudaru s većim krugom,
* prikaz tajmera tokom igre,
* pauziranje i nastavak igre,
* ponovno pokretanje igre nakon poraza,
* prikaz imena igrača na njegovom krugu,
* promjenu izgleda (skina) igračevog kruga,
* specijalne krugove sa dodatnim efektima.

## Korištene tehnologije
* HTML
* CSS
* JavaScript
* HTML5 Canvas

## Implementirani koncepti
Tokom razvoja projekta korišteni su:
* HTML5 Canvas za iscrtavanje elemenata igre,
* Game Loop za kontinuirano ažuriranje stanja igre,
* animacije i kretanje objekata,
* detekcija sudara korištenjem udaljenosti između centara krugova,
* nasumično generisanje i kretanje objekata,
* obrada događaja tastature,
* upravljanje stanjima igre (početak, pauza, poraz i restart).

## Pokretanje projekta
1. Klonirati repozitorij.
2. Otvoriti projekat u Visual Studio Code-u ili drugom editoru.
3. Pokrenuti datoteku `index.html` u internet pregledniku.
